LiveDeck demo deck

Click into any text on this slide and edit it like PowerPoint. Every change is written straight back to demo.html — the only the element you touched.

  • Select text and press ⌘B, ⌘I, or ⌘U
  • Press Enter in a bullet to add another one
  • Tab / Shift+Tab indent and outdent bullets
  • Alt+↑ / Alt+↓ reorder bullets
